# Support

- [Discord support](https://discord.gg/uw8HStQBAq)
- [WARDOGS connection guide](https://warguardian.app/wardogs-rcon/setup)

Use GitHub issues for public documentation corrections and general feature suggestions. Use Discord for account, billing or server-specific help.

Never post passwords, tokens, private server addresses, player records, unredacted logs or account details in public issues. For security reports, follow [SECURITY.md](SECURITY.md).

## Where to ask

| Request | Channel |
| --- | --- |
| WARDOGS RCON connection or panel problem | Discord support |
| Account access, community ownership or billing | Discord support; arrange a private conversation before sharing details |
| Incorrect public documentation | GitHub documentation correction issue |
| New game integration or feature suggestion | GitHub feature suggestion issue |
| Suspected vulnerability or unauthorized data exposure | Private security report |
| Player ban dispute | The community that issued the decision; platform access/privacy questions can go to WarGuardian support |

## Reporting a connection or administration problem

Include the game, the public page or feature you were using, what you expected, what happened and the approximate time with your time zone. A short reproduction sequence and the visible error wording are more useful than an unexplained screenshot.

For WARDOGS connection issues, check whether your hosting provider has enabled RCON and supplied the RCON port, which may differ from the game port. Tell support whether the initial connection check failed or a previously working connection stopped. Share provider or account details only through a private channel when needed.

For moderation or automation problems, distinguish a saved rule or decision from the reported game-server result. Describe the selected action and its visible status without identifying affected players publicly. Do not repeatedly issue a destructive command just to produce a support example.

## Screenshots and logs

Redact credentials, connection details, player identifiers and private community material before sharing. Send the smallest relevant excerpt. Do not upload full environment files, database exports or server configuration archives to this repository.

## Feature and integration requests

Describe the task, the game and the result you need. For self-hosting, explain which workflows must work without a central connection. For shared intelligence, explain the moderation decision you need help making and what source attribution you would expect.

Requests are useful planning input; an issue does not create a release date or guarantee that a proposed feature is available. Check [integration status](docs/integrations.md), [self-hosting](docs/self-hosting.md) and [shared-intelligence plans](docs/shared-intelligence.md) first.

## Service and policy questions

The [continuity commitment](docs/service-continuity.md) explains the open-source release promise if WarGuardian permanently ceases operation.
