# Open-source and service continuity commitment

WarGuardian's existing service continuity commitment is effective October 18, 2026 and is published with the [service policies](https://warguardian.app/legal).

> If WarGuardian permanently ceases operation, we will release all WarGuardian-owned code and models under open-source licenses.
>
> The release will include scoring rules, model files, and training and evaluation code.
>
> Private community and player data, credentials, and third-party material that we cannot redistribute will be excluded.
>
> Existing refund and data export rights remain unchanged.

## What the commitment covers

The commitment covers WarGuardian-owned application code and models, including the scoring, model and training/evaluation material named above. It is not limited to a reduced dashboard or a viewer-only application.

It does not authorize publishing community records, player data, credentials or third-party material that WarGuardian cannot redistribute. Releasing software is different from releasing the private data a hosted service processes.

## What triggers it

The stated trigger is WarGuardian permanently ceasing operation. An ordinary maintenance window, a delayed update or a temporary interruption is not a permanent shutdown announcement. The existing policy does not specify an inactivity timer or a fixed release deadline; none is invented here.

## Current licensing and availability

The application source and models are not distributed in this public documentation repository today. A future open-source release must include the actual software, its applicable licenses and the material covered by the commitment. A public README alone is not a software release, source escrow or a current open-source license grant.

The proposed self-hosted edition could arrive while WarGuardian continues operating. That is a separate product plan, not a condition that narrows or replaces the shutdown commitment. Read the [self-hosting direction](self-hosting.md) for its current status.

## Customer questions

Use [support](../SUPPORT.md) for questions about your account, export or service status. Existing terms govern refunds and export rights. Do not post private records in a public issue when asking for help.
