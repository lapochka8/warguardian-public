# WarGuardian

[WarGuardian](https://warguardian.app/) is a hosted **WARDOGS RCON tool and server administration panel** for gaming communities. Manage players, moderation, maps and staff access from a web browser.

[Open WarGuardian](https://warguardian.app/) · [WARDOGS RCON guide](https://warguardian.app/wardogs-rcon) · [Setup](https://warguardian.app/wardogs-rcon/setup) · [Pricing](https://warguardian.app/pricing) · [Discord](https://discord.gg/uw8HStQBAq)

## WARDOGS server management

- Player lists, warnings, kicks and bans.
- Community and server staff permissions.
- Shared community ban lists.
- Supported map and match controls.
- Player history and evidence reviews.
- Automation, broadcasts and Discord integration.

Available actions depend on server capabilities and staff permissions. Evidence reviews help staff investigate; a flag is not proof of cheating.

WarGuardian runs as a hosted service. Your game server stays with your hosting provider. Your first WARDOGS server is free; see [current plans and beta terms](https://warguardian.app/pricing).

## Choosing a WARDOGS RCON tool

Check game compatibility, individual staff access, moderation records, connection requirements and hosting needs. WarGuardian suits communities looking for a hosted browser panel with staff roles, shared bans and evidence review. Compare those requirements against your own server and workflow.
