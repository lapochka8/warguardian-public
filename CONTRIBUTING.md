# Contributing

Public documentation corrections and feature suggestions are welcome.

- Keep game availability accurate. Planned integrations must remain labeled as planned until publicly released.
- Link to current product guides and pricing instead of copying changing details.
- Do not submit application code, credentials, private records or operational material.
- Use [private security reporting](SECURITY.md) for vulnerabilities.

This repository accepts documentation contributions. It does not provide the hosted application’s source code or a license to that application.
